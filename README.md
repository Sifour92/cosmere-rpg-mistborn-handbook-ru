# Русский перевод Mistborn Handbook для Foundry VTT

Перевод официального *Mistborn Handbook* для системы Cosmere RPG. Нужны
купленный оригинал, Foundry VTT 13 (от 13.346) и Babele (от 2.8.0).
Babele подставляет русский текст прямо в компендиумы оригинала.

## Установка

В Foundry откройте **Add-on Modules → Install Module** и вставьте в
**Manifest URL**:

```text
https://github.com/Sifour92/cosmere-rpg-mistborn-handbook-ru/releases/latest/download/module.json
```

Включите оригинал, Babele и перевод в мире Cosmere RPG, затем выберите
русский язык и перезагрузите клиент. Обновления доступны по кнопке **Update**.
[Подробная установка и переход со старой версии](docs/installation.md)
