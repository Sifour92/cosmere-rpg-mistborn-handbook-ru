# Русский перевод Mistborn Handbook для Foundry VTT

Отдельный модуль перевода справочника «Рождённый туманом» (Mistborn Handbook)
для системы Cosmere RPG. Работает вместе с оригинальным модулем
`cosmere-rpg-mistborn-handbook` и Babele.

## Состояние

Версия **0.0.1 — каркас проекта**. Созданы манифест, подключение Babele,
каталоги локализации, документация и проверка файлов.
Переводы ещё не включены: `lang/ru.json` пуст, файлов переводов компендиумов нет.
Работа в самом Foundry пока не проверена.

Первый содержательный выпуск — глава 6. Полная цель — перевод книги,
всех 12 компендиумов и 76 строк интерфейса исходника 1.0.1.

## Разработка

Для проверки нужен Node.js 20 или новее с npm. Внешних npm-зависимостей
на этом этапе нет; запускать `npm install` не требуется.

Из корня этого проекта:

```bash
npm run check
```

Команда проверяет JSON, согласованность версии, объявленные зависимости,
наличие подключённых файлов и синтаксис скрипта. Проверка в Foundry — отдельный этап.

## Внешние материалы

Оригинальный справочник, общий глоссарий и прежние переводы хранятся отдельно
от этого проекта. В текущей общей рабочей папке они находятся здесь
(пути относительно корня этого проекта):

- `../cosmere-rpg-mistborn-handbook/` — исходный модуль версии 1.0.1.
- `../../../../cosmere-glossary.md` — основной глоссарий проекта.
- `../../../../translations/mistborn/` — прежние тексты и выгрузки.
- `../../../../CLAUDE.md` — общие правила родительского проекта.

Если репозиторий перенесён в другое место, расположение этих входных
материалов нужно определить заново. `npm run check` от них не зависит.
Для рабочих копий исходников предусмотрен каталог `.local/`, исключённый из Git.

## Установка для проверки

Целевая среда — Foundry VTT 13, начиная с 13.346; система `cosmere-rpg`,
исходный справочник и Babele ветки 2.7.x с его зависимостями.
Конкретные проверенные версии будут записаны после испытаний.

1. Поместить папку `cosmere-rpg-mistborn-handbook-ru` в `Data/modules/`.
2. Перезапустить Foundry, если это нужно для обнаружения нового модуля.
3. Включить оригинальный справочник, Babele, его зависимости и этот модуль.
4. Выбрать русский язык Foundry и перезагрузить клиент.

Текущая версия только подключает каталог перевода, поэтому содержимое
справочника останется на английском. Подключение будущего перевода
не предполагает автоматическую перезапись уже импортированных документов мира.

## Git

Корень будущего репозитория — эта папка, содержащая `module.json`.
`.gitignore` уже исключает зависимости, локальные исходники, результаты
сборки и служебные файлы. Git и удалённый репозиторий подключает пользователь.

## Терминология

**Любые неизвестные термины, имена и названия согласовываем с пользователем.**
Показываем оригинал, контекст и предлагаемый перевод. До решения сохраняем
английский вариант. Это правило относится и к прежним переводам.

Термины и названия сопровождаются английским вариантом в скобках с
исключениями из [правил проекта](AGENTS.md).
