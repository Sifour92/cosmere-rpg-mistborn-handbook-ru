# Русский перевод Mistborn Handbook для Foundry VTT

**Перевод поверх купленного официального модуля
`cosmere-rpg-mistborn-handbook`.** Сначала устанавливается оригинал,
затем в мире включается дополнение `cosmere-rpg-mistborn-handbook-ru`.
Babele подставляет русский текст в компендиумы оригинала.

Книга, изображения и механика загружаются из официального модуля.
Открывать нужно его компендиум справочника «Рождённый туманом» (Mistborn Handbook).
Дополнение содержит только перевод и код его подключения; своих компендиумов
у него нет. Файлы купленного модуля сохраняются без изменений.

## Как это работает

Модуль не содержит ни книги, ни компендиумов. Это тонкая прослойка из трёх частей:

1. **Оригинал** `cosmere-rpg-mistborn-handbook` хранит всё содержимое: журналы,
   предметы, силы, таблицы, картинки, механику. Его файлы мы не трогаем.
2. **Babele** — модуль Foundry, который «на лету» подменяет тексты документов
   в компендиумах, когда выбран нужный язык. Сами базы данных он не меняет.
3. **Это дополнение** говорит Babele, где лежат русские тексты. Скрипт
   [`scripts/register.mjs`](scripts/register.mjs) на событии `babele.init`
   регистрирует папку [`translations/ru/`](translations/ru/) для языка `ru`.

Что происходит, когда вы открываете компендиум оригинала при русском
интерфейсе Foundry:

1. Babele берёт английский документ из компендиума оригинала.
2. Находит в `translations/ru/` файл с таким же именем коллекции
   (`cosmere-rpg-mistborn-handbook.<компендиум>.json`) и запись с **таким же `_id`**,
   как у документа.
3. Заменяет в документе только перечисленные в записи поля (название, описание,
   текст страниц, вложенные действия). Всё остальное — формулы, ссылки,
   картинки, числа — остаётся от оригинала.
4. Если записи для документа нет, остаётся английский текст.

Поэтому перевод **заменяется, а не копируется**: отключите дополнение и
перезагрузите клиент, и те же компендиумы снова станут английскими. Документы,
уже импортированные в мир, это не затрагивает: Babele применяется только к
компендиумам.

Отдельные части:

- [`lang/ru.json`](lang/ru.json) — строки интерфейса (76 штук), подхватываются
  Foundry как обычный языковой файл.
- [`scripts/labels.mjs`](scripts/labels.mjs) — словарь «английская строка →
  русская» для подписей в деревьях талантов и заголовков диалогов выбора:
  эти данные лежат глубоко внутри документов, и Babele-конвертеры
  `cosmereTreeLabels` и `cosmereEventLabels` из `register.mjs` меняют их по
  точному совпадению строки.
- [`styles/translation.css`](styles/translation.css) — шрифты и переносы заголовков;
  действует только при русском языке.

## Где русский перевод и как его править

Весь перевод — в **[`translations/ru/`](translations/ru/)**, по одному JSON-файлу
на каждый из 12 компендиумов:

| Файл | Что внутри |
|---|---|
| `…handbook.json` | книга: 21 журнал и все страницы (HTML) |
| `…metallic-arts.json` | силы алломантии и ферухимии, таланты, вложенные действия |
| `…metalborn-paths.json`, `…heroic-paths.json` | пути, деревья и таланты |
| `…ancestries.json`, `…cultures.json` | наследия и культуры |
| `…items.json`, `…actions.json` | предметы и базовые действия |
| `…roll-tables.json` | таблицы и их результаты |
| `…animal-companions.json`, `…adversary-features.json` | существа и особенности |
| `…macros.json` | название макроса |

Устройство файла (на примере `items.json`):

```json
{
  "mapping": { "description": "system.description.value" },
  "entries": {
    "<_id документа>": {
      "name": "Камертон (Tuning Fork)",
      "description": "<p>Текст с сохранённой HTML-разметкой.</p>"
    }
  }
}
```

- `mapping` говорит Babele, какое поле документа заменяет какой ключ записи
  (`description` → `system.description.value`).
- `entries` — сами переводы. **Ключ — это `_id` документа в оригинале**, а не его
  название. Для журналов страницы вложены: `pages` → `<_id страницы>` → `name`, `text`.
  Для вложенных действий и предметов — `items` / `actions` → `<_id>` → поля.
- Названия папок лежат в `folders` («английское название → русское»).

### Как найти документ, который надо поправить

1. Откройте компендиум в Foundry на русском и найдите нужный текст.
2. Узнайте `_id`: правая кнопка на документе → «Копировать ID документа»
   (или `Копировать UUID`; последний сегмент UUID — это `_id`).
   Для страницы журнала `_id` страницы — последний сегмент её UUID.
3. Найдите этот `_id` в нужном файле из `translations/ru/` и правьте строку.

Чтобы видеть английский оригинал рядом, соберите локальный снимок
`.local/source/snapshot.json` командой `npm run extract` (см. «Разработка»).

### Правила правки

- **Не меняйте** `_id`, UUID-ссылки (`@UUID[...]`, `@Embed[...]`), формулы
  (`[[/r 4d8]]`, `[[damage ...]]`), значки (`<span class="cosmere-icon">`), числа и
  HTML-теги. Меняйте только видимый текст между ними.
- Названия, имена и игровые термины пишутся «по-русски (English)». Исключения и
  принятые варианты — в [AGENTS.md](AGENTS.md) и [реестре терминов](docs/terms.md).
  Нового термина в реестре нет — не придумывайте молча: предложите вариант
  в описании правки (оригинал, контекст, перевод).
- Подписи в деревьях талантов (`label`, `pickPromptTitle`) переводятся не в JSON,
  а в [`scripts/labels.mjs`](scripts/labels.mjs).
- Правите строки интерфейса — смотрите [`lang/ru.json`](lang/ru.json): структура
  ключей совпадает с оригиналом, ключи не переводятся.

### Как проверить и предложить правку

```bash
npm run check   # JSON, версии, зависимости, файлы, синтаксис скриптов
npm run pack    # соберёт dist/cosmere-rpg-mistborn-handbook-ru.zip
```

Для проверки в игре замените папку `Data/modules/cosmere-rpg-mistborn-handbook-ru/`
файлами из ZIP, перезапустите Foundry и перезагрузите клиент (Cmd/Ctrl+Shift+R).
Работайте в тестовом мире. Оригинальный модуль редактировать нельзя и не нужно.
Правки присылайте обычным pull request в репозиторий; в описании укажите,
какой документ и почему меняется.

## Установка и включение

Целевая среда — Foundry VTT 13, начиная с 13.346, с системой `cosmere-rpg`.

1. Установить купленный официальный `cosmere-rpg-mistborn-handbook` обычным
   способом через Foundry и включить его в мире Cosmere RPG.
2. Установить Babele и его зависимости. Babele применяет перевод к документам
   оригинала.
3. Распаковать ZIP перевода в `Data/modules/` (собирается `npm run pack`; папка должна называться ровно `cosmere-rpg-mistborn-handbook-ru`, без версии и суффиксов, иначе Foundry пишет «Invalid module»). Должен получиться файл
   `Data/modules/cosmere-rpg-mistborn-handbook-ru/module.json` рядом с папкой
   оригинала `Data/modules/cosmere-rpg-mistborn-handbook/`.
4. Перезапустить Foundry для обнаружения дополнения. В управлении модулями
   включить «Русский перевод для официального Mistborn Handbook», Babele
   и его зависимости. Официальный модуль должен оставаться включённым.
5. Выбрать русский язык Foundry и перезагрузить клиент.
6. Открыть книгу в компендиуме официального модуля. Готовые переводы
   подставятся в его страницы; остальные страницы сохранят английский текст.

Копировать файлы перевода внутрь папки оригинала или импортировать отдельную
русскую книгу не требуется. Каталог перевода регистрируется автоматически:
поле пользовательского каталога Babele настраивать не нужно.

Чтобы вернуть английский текст компендиумов, отключить только дополнение
перевода и перезагрузить клиент. Уже импортированные документы мира —
сохранённые копии; включение и отключение дополнения их не перезаписывает.

## Разработка

Для проверки нужен Node.js 20 или новее с npm. Внешних npm-зависимостей
на этом этапе нет; запускать `npm install` не требуется.

Из корня этого проекта:

```bash
npm run check
```

Команда проверяет JSON, согласованность версии, объявленные зависимости,
отсутствие собственных компендиумов, наличие подключённых файлов и синтаксис
скриптов. Проверка в Foundry — отдельный этап.

Чтобы получить читаемый снимок оригинала 1.0.1, укажи каталог `app`
установленного Foundry. Пример для macOS:

```bash
npm run extract -- '/Applications/Foundry Virtual Tabletop.app/Contents/Resources/app'
```

Вторым аргументом можно передать путь к оригиналу. По умолчанию используется
соседняя папка `cosmere-rpg-mistborn-handbook`. Команда читает копии LevelDB
через библиотеку установленного Foundry и сохраняет снимок в
`.local/source/snapshot.json`. В снимке есть контрольные суммы оригинальных файлов.

Локальная проверка подключения к Babele 2.9.1 после извлечения снимка
(пути к установленным Foundry и Babele для macOS):

```bash
npm run check:overlay -- \
  '/Applications/Foundry Virtual Tabletop.app/Contents/Resources/app' \
  "$HOME/Library/Application Support/FoundryVTT/Data/modules/babele"
```

Проверка выполняет `scripts/register.mjs`, обнаруживает файлы перевода
через движок установленной Babele и применяет их к исходной коллекции.
Проверяются русский и английский языки, отсутствие регистрации перевода,
сохранность исходных данных. Это проверка в Node.js с имитацией файловых
запросов Foundry; интерфейс и включение модулей в игровом мире проверяются отдельно.

## Проверка в игровом мире

Версии среды и результаты испытаний записываются в
[отчёт проверок](docs/validation.md).

В тестовом мире Cosmere RPG открыть главу 6 в компендиуме справочника.
Из введения перейти по ссылке «Металлы Скадриаля» (Metals of Scadrial).
В разделе «Использование Металлических искусств» (Using Metallic Arts)
проверить заголовки, значки действий и встроенные таблицы. На страницах
Алюминиевой и Хромовой алломантии (Aluminum Allomancy, Chromium Allomancy)
проверить встроенные действия сжигания. На страницах Золотой и Цинковой
ферухимии (Gold Feruchemy, Zinc Feruchemy) проверить карточки накопления
и черпания и переходы по ссылкам.
На страницах Железной, Стальной и Оловянной алломантии (Iron, Steel, and
Tin Allomancy) проверить три действия сжигания, перемещение, атаки и
ссылку на сверхъестественные чувства (Supernatural Senses). На страницах
Медной, Бронзовой, Латунной и Цинковой алломантии (Copper, Bronze, Brass,
and Zinc Allomancy) открыть действия сжигания, а в самой карточке Бронзовой
алломантии (Bronze Allomancy) проверить действие «Распознать силу» (Identify).
В карточке «Накапливать воспоминание» (Store Memory) проверить таблицу
длительности и ссылку на приложение. Проверить карточки временных пузырей
кадмия и bendalloy, а также ссылки из действий atium.
Отключить дополнение перевода, оставив оригинал активным, и перезагрузить
клиент: та же глава должна открываться на английском. Повторно включить
дополнение: готовые страницы должны снова отображаться по-русски.
Отдельно проверить английский язык Foundry при включённом дополнении.

## Терминология

**Любые неизвестные термины, имена и названия согласовываем с пользователем.**
Показываем оригинал, контекст и предлагаемый перевод. До решения сохраняем
английский вариант. Это правило относится и к прежним переводам.

Термины и названия сопровождаются английским вариантом в скобках с
исключениями из [правил проекта](AGENTS.md).
