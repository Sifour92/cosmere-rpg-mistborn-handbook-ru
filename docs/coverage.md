## Состояние сборки 0.2.4

Оригинал Mistborn Handbook 1.0.1. По каждому ID и полю покрытие сверяет
`npm run check:overlay` на снимке оригинала. Идентификаторы документов указаны
в `entries`, вложенные записи находятся в `pages`, `actions`, `items`,
`effects` и `results` внутри этих записей. Имена внутренних папок хранятся
в `folders` и проверяются по ID папок оригинала.

в книге нет. Из 255 вставок осталось перевести 18 действий, 167 талантов
и 32 дерева талантов. Термины в ожидании согласования видны в тексте
на английском.

14.11.2026 (см. [terms.md](terms.md)). Остаются по-английски до согласования:
названия, которых нет в terms.md (например, из ещё не переведённых глав).

Проверка автоматическая и выборочная, не полная вычитка глазами.
