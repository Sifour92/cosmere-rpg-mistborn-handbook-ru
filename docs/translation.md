# Как править перевод

Переводы документов хранятся в [`translations/ru/`](../translations/ru/), по одному
JSON-файлу на компендиум.

| Файл | Что внутри |
|---|---|
| `…handbook.json` | книга: 21 журнал и все страницы (HTML) |
| `…metallic-arts.json` | силы алломантии и ферухимии, таланты, вложенные действия |
| `…metalborn-paths.json`, `…heroic-paths.json` | пути, деревья и таланты |
| `…ancestries.json`, `…cultures.json` | наследия и культуры |
| `…items.json`, `…actions.json` | предметы и базовые действия |
| `…roll-tables.json` | таблицы и их результаты |
| `…animal-companions.json`, `…adversary-features.json` | существа и особенности |
| `…macros.json` | название макроса |

Устройство файла (на примере `items.json`):

```json
{
  "mapping": { "description": "system.description.value" },
  "entries": {
    "<_id документа>": {
      "name": "Камертон (Tuning Fork)",
      "description": "<p>Текст с сохранённой HTML-разметкой.</p>"
    }
  }
}
```

- `mapping` говорит Babele, какое поле документа заменяет какой ключ записи
  (`description` → `system.description.value`).
- В `entries` ключом служит **`_id` документа в оригинале**. Ищите страницы
  журнала по пути `pages` → `<_id страницы>` → `name`, `text`, а вложенные
  действия и предметы по пути `items` или `actions` → `<_id>` → нужное поле.
- Названия папок лежат в `folders` («английское название → русское»).

## Как найти документ, который надо поправить

1. Откройте компендиум в Foundry на русском и найдите нужный текст.
2. Щёлкните по документу правой кнопкой и выберите «Копировать ID документа».
   Если доступно «Копировать UUID», возьмите последний сегмент UUID.
   Для страницы журнала `_id` страницы — последний сегмент её UUID.
3. Найдите этот `_id` в нужном файле из `translations/ru/` и правьте строку.

Чтобы видеть английский оригинал рядом, соберите локальный снимок
`.local/source/snapshot.json` командой `npm run extract`. [Как извлечь оригинал](development.md#снимок-оригинала)

## Правила правки

- **Не меняйте** `_id`, UUID-ссылки (`@UUID[...]`, `@Embed[...]`), формулы
  (`[[/r 4d8]]`, `[[damage ...]]`), значки (`<span class="cosmere-icon">`), числа и
  HTML-теги. Меняйте только видимый текст между ними.
- Названия, имена и игровые термины пишутся «по-русски (English)». Исключения и
  принятые варианты — в [правилах проекта](../AGENTS.md) и общем глоссарии. [Где лежит глоссарий](development.md#внешние-материалы)
  Новые термины, имена и названия согласуйте до включения в перевод. Покажите
  оригинал, контекст и свой вариант. До согласования сохраняйте английский
  текст, в том числе при работе с прежними переводами. [Очередь согласования](terms.md)
- Подписи в деревьях талантов (`label`, `pickPromptTitle`) правьте в
  [`scripts/labels.mjs`](../scripts/labels.mjs).
- Строки интерфейса правьте в [`lang/ru.json`](../lang/ru.json). Сохраняйте
  ключи и структуру файла.

## Покрытие перевода

С версии **0.2.0** переведены все 12 компендиумов оригинала 1.0.1
(916 документов), 76 строк интерфейса оригинала и подпись Алломантии
на листе персонажа системы Cosmere.

| Компендиум | Что переведено |
|---|---|
| `handbook` | вся книга, 21 журнал: введение, главы 1–13, приложения 1–3, глоссарий и указатель, благодарности, авторские права |
| `metallic-arts` | 267 документов: силы, талант-деревья и вложенные действия |
| `metalborn-paths` | пути металлорождённых, деревья, 38 талантов, 51 цель |
| `heroic-paths` | 6 путей, 24 дерева, 150 талантов |
| `ancestries`, `cultures` | 3 наследия и 15 культур, списки имён |
| `items`, `actions` | 246 предметов и 21 базовое действие |
| `roll-tables` | 6 таблиц, результаты и диапазоны |
| `animal-companions`, `adversary-features` | 9 спутников-животных, 33 особенности |
| `macros` | название макроса «Поглотить кости» |

Подписи в деревьях талантов и окнах выбора обрабатывают конвертеры
`cosmereTreeLabels` и `cosmereEventLabels` из [`scripts/register.mjs`](../scripts/register.mjs).
Они ищут точное совпадение в словаре [`scripts/labels.mjs`](../scripts/labels.mjs).

Без перевода остаются `alt` иллюстраций, служебные названия правил событий,
подписи экспертиз в обработчиках и код макроса «Поглотить кости». Интерфейс самой
системы Cosmere RPG находится за пределами этого перевода.

Для вложенных действий нужен Babele 2.8.0 или новее. Подключение проверено
на Babele 2.9.1. [Формат вложенных документов](https://gitlab.com/riccisi/foundryvtt-babele/-/raw/master/DEVELOPER_MIGRATION_2_8_0.md#documentconverter-and-embedded-documents)

Для журналов используется Georgia (запасной шрифт Times New Roman), для
остального интерфейса используется Roboto Condensed. Стили действуют при русском
языке и включённом модуле. [Файл стилей](../styles/translation.css)

Подробнее о составе перевода и проверках см. в [реестре покрытия](coverage.md)
и [отчёте проверок](validation.md). Ошибка консоли `getEnricherData is not a function`
воспроизводится и на английском оригинале.
