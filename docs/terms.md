# Очередь согласования переводов

Открытых вопросов нет. Пять названий из очереди утверждены 17.11.2026 и внесены в [системный глоссарий](../../../../../glossary/system.md).

Для нового вопроса записать английский оригинал, UUID или место в источнике,
контекст и предложенные русские варианты. До решения сохранять английский
оригинал. Отсутствие ответа сохраняет вопрос открытым.

После согласования внести перевод, контекст, источник и дату в соответствующий
тематический файл глоссария и убрать вопрос из очереди. Поиск вести во всех
разделах, включая общую механику и указатель талантов.
