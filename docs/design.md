# Устройство модуля

Дата: 12.11.2026. Пользователь выбрал отдельный модуль перевода,
подключаемый вместе с оригинальным Mistborn Handbook.

## Работа в Foundry

Оригинал `cosmere-rpg-mistborn-handbook` предоставляет документы, изображения
и механику. Наш пакет `cosmere-rpg-mistborn-handbook-ru` предоставляет
русский интерфейс через `lang/ru.json` и перевод компендиумов через Babele.

Порядок использования: установить и активировать купленный оригинал,
затем активировать Babele и дополнение перевода. При русском языке Foundry
перевод отображается в тех же компендиумах и документах оригинала.
У дополнения нет собственных `packs` или `packFolders`; отдельная копия книги
не создаётся. Отключение дополнения с перезагрузкой возвращает английское
содержимое компендиумов. Оригинальные файлы при этом не изменяются.

Регистрация выполняется в событии `babele.init` с языком `ru` и каталогом
`translations/ru`. Файлы называются по исходным коллекциям, например
`cosmere-rpg-mistborn-handbook.handbook.json`. Документы и вложенные страницы
сопоставляются по исходным ID. При отсутствии перевода остаётся оригинал.

Целевая среда — Foundry 13 и исходник 1.0.1. Для Babele в манифесте указан
минимум 2.8.0 для сопоставления вложенных действий. Сопоставление по ID
проверено на установленной Babele 2.9.1.
Перевод остальных частей системы
`cosmere-rpg` в этот пакет не входит.

## Состав проекта

| Часть | Назначение |
|---|---|
| `module.json` | Подключение к Foundry, язык и зависимости |
| `scripts/register.mjs` | Регистрация каталога в Babele |
| `styles/translation.css` | Georgia и перенос длинных заголовков русской версии |
| `lang/ru.json` | Пользовательские строки интерфейса |
| `translations/ru/` | Переводы по компендиумам |
| `tools/` | Проверка файлов и подготовка данных |
| `docs/` | План, решения и результаты будущих проверок |
| `.local/` | Локальные исходники и промежуточные данные вне Git |

## Правила содержимого

- ID, UUID, типы документов, числовые параметры, формулы, флаги и пути
  изображений сохраняются.
- HTML-разметка, встроенные команды и якоря проверяются при переносе текста.
- Старые переводы сверяются с актуальным исходником; совпадение ID не
  подтверждает неизменность содержимого.
- Неизвестные термины, имена и названия согласуются с пользователем.
  Подробный порядок — в [terms.md](terms.md).
- Формат русских и английских названий — по [AGENTS.md](../AGENTS.md).
- Уже импортированные документы мира автоматически не перезаписываются.
- Локальные исходники и оригинальные базы не включаются в устанавливаемый архив.

## Результат

Версия 0.1.10 содержит текст всех 38 страниц главы 6, пять встроенных
таблиц, 25 сил с 39 вложенными действиями и часть интерфейса.
Покрытие и оставшиеся материалы перечислены в [coverage.md](coverage.md).

Полная версия включает пользовательские тексты всех 12 компендиумов и
интерфейс исходного модуля. Неизвестные термины согласованы, переходы и
механика проверены, инструкция соответствует содержимому архива.

Проверки JSON и синтаксиса отделяются от испытаний в настоящем Foundry.
Если испытания не выполнены, это явно указывается в описании сборки.

## Русское оформление

По выбору пользователя от 12.11.2026 текст и заголовки справочника используют
Georgia. Основной текст имеет начертание 400 и межстрочный интервал 1.5.
Системные шрифты берутся из ОС, файлы шрифтов оригинала не копируются.
Длинные заголовки переносятся, карточка компендиума увеличивает высоту,
сохраняя место для подписи источника.

Стили ограничены `html[lang="ru"]`, классом официального журнала `.mbjhb`
и карточкой с `data-pack="cosmere-rpg-mistborn-handbook.handbook"`.
Класс журнала назначает оригинал, включая копии с его `compendiumSource`.
Другие книги и интерфейс Foundry используют прежнее оформление.
