# Установка и обновление

## Установка и включение

Целевая среда — Foundry VTT 13, начиная с 13.346, с системой `cosmere-rpg`.

1. Установить купленный официальный `cosmere-rpg-mistborn-handbook` обычным
   способом через Foundry и включить его в мире Cosmere RPG.
2. Установить Babele и libWrapper. Babele применяет перевод к документам
   оригинала.
3. На экране настройки Foundry открыть **Add-on Modules → Install Module**
   и вставить в поле **Manifest URL** следующий адрес. Нажать **Install**.

   ```text
   https://github.com/Sifour92/cosmere-rpg-mistborn-handbook-ru/releases/latest/download/module.json
   ```

4. В управлении модулями мира включить «Русский перевод для официального Mistborn Handbook», Babele
   и его зависимости. Официальный модуль должен оставаться включённым.
5. Выбрать русский язык Foundry и перезагрузить клиент.
6. Открыть книгу в компендиуме официального модуля. Babele подставит
   русский текст в страницы книги и карточки компендиумов.

Для перевода меню самой Foundry можно дополнительно включить `ru-ru`
13.351.54. Совместная работа проверена на Foundry 13.351.
[Русский интерфейс для Foundry 13](https://github.com/phenomen/foundry-vtt-ru/releases/tag/release-v13)

Копировать файлы перевода внутрь папки оригинала или импортировать отдельную
русскую книгу не требуется. Каталог перевода регистрируется автоматически:
поле пользовательского каталога Babele настраивать не нужно.

Чтобы вернуть английский текст компендиумов, отключить только дополнение
перевода и перезагрузить клиент. Уже импортированные документы мира —
сохранённые копии; включение и отключение дополнения их не перезаписывает.

## Обновление

На экране настройки Foundry открыть **Add-on Modules** и нажать **Update**
рядом с модулем перевода. Foundry проверит ту же ссылку и установит новую
версию, когда она появится.

После обновления сверьте номер версии на карточке модуля в **Add-on Modules**.
При ошибке **Timed Out** повторите **Update**. Если кнопки обновления нет
у вручную установленной копии или тайм-аут повторяется, скачайте ZIP из
[последнего релиза](https://github.com/Sifour92/cosmere-rpg-mistborn-handbook-ru/releases/latest).
Остановите Foundry, переместите прежнюю папку
`cosmere-rpg-mistborn-handbook-ru` за пределы `Data/modules/` и распакуйте
новую из ZIP в `Data/modules/`. Запустите Foundry и сверьте версию. Манифест
из ZIP содержит адрес для следующих обновлений.

## Если справочник остался на английском

В мире Cosmere RPG откройте **Game Settings → Manage Modules** и проверьте,
что включены Mistborn Handbook, Babele, libWrapper и модуль перевода.
В **Game Settings → Configure Settings → Language Preference** выберите
**Русский** и согласитесь на перезагрузку. Повторите это в каждом браузере,
где нужен перевод. При выборе **English** Babele ищет файлы для `en` и
оставляет справочник на английском даже при включённом модуле.

Откройте справочник заново через **Compendium Packs**. Документы, которые
были импортированы в мир до включения перевода, сохраняют текст на момент
импорта.
